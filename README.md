**What will be the name of the App?**
Hexarium

**What is the Theme of the App?**
Hexarium is a modern dark-fantasy archive of magical beings and knowledge.
The app takes place in a fictional world where witches, wizards, high priestesses, alchemists and other magical beings are documented according to their powers, elements, specialties and rank.
Instead of a traditional parchment-style witch website, the visual direction will feel like a mysterious digital occult archive — dark, elegant and slightly otherworldly, with glowing elements, celestial symbols, magical illustrations and rich character imagery.
Users can discover characters such as Blood Witches, Plant Witches, Love Witches, Moon Witches, Necromancers and Grand Wizards, and explore the spells connected to them.

**What are the main functionalities?**
- Browse a collection of magical characters
- View a detailed profile for each character, including their:
  - magical type
  - element
  - powers
  - specialty
  - rank
  - power level
  - description
  - related spells
  - coven
- Search characters by name
- Filter characters by properties such as type or element
- Create a new magical character
- Edit an existing character
- Delete a character
- Browse a separate collection of spells
- View detailed information about individual spells
- Display the relationship between witches and their associated spells
- Navigate between related character and spell records
- Include responsive mobile and desktop layouts
- Include loading and error states when retrieving data

**Possible bonus features**
